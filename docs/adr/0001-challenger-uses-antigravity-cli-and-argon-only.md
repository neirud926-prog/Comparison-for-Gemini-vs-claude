# Challenger Build uses Antigravity CLI with Gemini 4 Argon only

Jules is Google's closest match to Claude Code's cloud sessions (cloud VM, GitHub PRs, usable from a phone browser), but it does not run Gemini 4 Argon and shows no sign of loading project skills. Argon and the same skills are the point of the comparison, so the Challenger Build runs in Antigravity CLI on a PC, on a plan that includes Argon in Antigravity, and no other model. Phone use is not scored. The Reference Build's Opus/Sonnet mix (24/8 commits) is recorded as it was, not matched.
